NotMyNet for Windows

Requirements: Windows 11 x64. No installer or administrator privileges are required.
Extract the entire ZIP, then open notmynet-windows.exe. Try 127.0.0.1 and click Start.
This is an early release and is unsigned; Windows SmartScreen may warn about it.
The release page provides a SHA-256 checksum for the ZIP.

Settings are kept in %LOCALAPPDATA%\NotMyNet\settings.txt. Probe history is not saved.
Report issues at https://github.com/Momentum-Free/NotMyNet/issues (include the release
version, Windows version, and steps to reproduce; omit private addresses and hostnames).
